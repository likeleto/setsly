# AGENTS.md — Workout Tracker

SPA-трекер тренировок: React 19 + TS + Vite, Tailwind 4 + shadcn/ui, данные в `localStorage`.
Запуск: `npm run dev` (порт 3000). Проверка: `npm run build`.

## Инварианты
- `localStorage` — только через `src/store`. Компоненты не трогают storage напрямую.
- `generateId()` — только из `@/utils/id`, копий не создавать.
- Импорты внутри `src` — через `@/...`.
- UI — только `src/components/ui/*` и токены `@theme`; хардкод цветов не добавлять.
- Без `window.alert` / `window.confirm` — inline-ошибки и состояние.
- Кнопки сохранения — с защитой от двойного клика.
- Новая зависимость или смена стека — только после согласования, с записью в `decisions.md`.

## Готово, когда
`npm run build` проходит и выполнены три проверки из `prd.md` (сохранение → история, 375px, персистентность).

## Документы
- `prd.md` — продукт и актуальный стек
- `data-model.md` — сущности, связи, правила хранения
- `fix-plan.md` — техдолг со статусами
- `auth-plan.md` — вход и пользователи
- `decisions.md` — почему менялись решения
